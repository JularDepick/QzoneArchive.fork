# 数据与安全

## 数据在哪里

归档数据优先保存在用户目录下的 `.qzonearchive.fork` 目录(Windows 为 `%USERPROFILE%\.qzonearchive.fork`,macOS 与 Linux 为 `~/.qzonearchive.fork`)。如果该位置不可写,程序会自动回退到应用所在目录(安装目录或运行目录)下的 `.qzonearchive.fork` 目录;也可以用环境变量 `QZA_DATA_DIR` 显式指定数据目录。

该目录内的内容是:

- `qzone-archive.sqlite3`:归档数据库,保存动态、互动记录、分页游标与限流状态
- `images/`:图片归档
- `videos/`:视频缓存
- 应用运行时的日志与 Chromium 用户数据

导出的 HTML 或媒体文件保存在你选择的导出位置。这些数据不自动上传到项目服务器。

## 登录凭证

登录凭证保存在主进程内存中,不写入日志,也不导出到文件。为让依赖登录态的窗口(网页登录、口令验证、QQ 空间)正常工作,凭证会写入应用自己的 Electron 会话,会话数据位于上述数据目录内。不要在不受信任的设备上登录,也不要将 Cookie、数据库文件或导出文件发送给陌生人。

## 建议的备份方式

- 对重要归档定期导出 HTML,并保存到受信任的加密存储介质。
- 升级、清理数据目录或卸载前,确认备份可被正常打开。
- 将本工具限制在本人账号或书面获得授权的资料范围内。
